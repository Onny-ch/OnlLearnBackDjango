## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Onny-ch/OnlLearnBackDjango.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Запушьте репозиторий в свой github аккаунт
4. Сделайте копию .env.sample, заполните его своими данными, переименовав в .env
5. В {secrets} github'а добавьте все переменные, использующиеся в файле .github/workflows.ci.yml

## Использование:

1. Функционал можно протестировать запустив сервер командой 
```
python manage.py runserver
```
и работать с данными через приложение Postman.

2. Для проверки работы через docker-compose необходимо сначала создать контейнер командой
```
docker build -t your-django-app .
```
затем, после запуска docker desktop, прописать команду 
```
docker-compose up -d --build
```
для запуска всех сервисов. Работу дальнейшая работа проводится по адресу
```
http://localhost:8000/
```
3. Настройка сервера.
Подключитесь к серверу через командную строку и выполняйте следующие команды для его настройки:
    - sudo apt update  # Команда для обновления списка пакетов
    - sudo apt upgrade  # Команда для обновления всех установленных пакетов до их последних версий
    - sudo ufw enable  # Активация фаервола
    - sudo ufw status  # Проверка состояния фаервола 
    - sudo ufw allow 80/tcp  # Команда на открытие порта 80
    - sudo ufw allow 443/tcp  # Команда на открытие порта 443
    - sudo ufw allow 22/tcp  # Команда на открытие порта 22
    - sudo ufw status  # Проверка открытия портов

4. Для запуска workflow и deploy приложения необходимо исполнить команду push или pull. Результаты можно посмотреть в
вашем github аккаунте во вкладке 'Actions' вашего репозитория
