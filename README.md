# Домашнее задание: *Платформа онлайн-обучения*"

## Описание функционала:

- есть приложения materials и users
- в приложении materials есть две модели: Course и Lesson
- в приложении users две модели: User и Payments
- сделаны фикстуры для моделей User и Payments
- реализован CRUD для модели Course через Viewsets, написан простейший сериализатор
- реализован CRUD для модели Lesson через Generic-классы, написан простейший сериализатор
- реализован CRUD для модели Payments через Viewsets
- добавлена сортировка по дате оплаты
- добавлены фильтрация по курсу, по уроку и по способу оплаты
- добавлены ограничения доступа. Делать что-либо можно только авторизованным пользователям
- добавлена группа модераторов
- расписаны ограничения доступа для создателей курсов, уроков и для модераторов


## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Onny-ch/OnlLearnBackDjango.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Сделайте копию .env.sample, заполните его своими данными, переименовав в .env


## Использование:

На данный момент функционал можно протестировать запустив сервер командой "python manage.py runserver" и работать с
данными через приложение Postman
